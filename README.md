# claude-skills

Personal Claude Code skills. Designed to compose with the
[mattpocock/skills](https://github.com/mattpocock/skills) engineering workflow.

| Skill | What it does |
| --- | --- |
| **autopilot** | Take a well-defined arc from a human-authored charter to merged-on-main with no supervision: charter interview (clickable, phone-friendly) → preflight → a self-scheduling chain of Claude Code web sessions running map → decisions → spec → tickets → parallel TDD build waves → per-ticket squash-merged PRs. Replaces the former `to-charter` + `unattended-flow` pair. |
| **check-in** | Fast status read: task progress, then the git chain (working tree → unpushed → branch → PR → main). |
| **navigate** | Orient inside the Matt Pocock workflow and route to the next step. *(Predates autopilot — routing names need a refresh.)* |
| **web-design-guidelines** | Review UI code against Web Interface Guidelines. |
